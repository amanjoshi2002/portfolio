# TruthCourt – AI-Powered Courtroom Simulation

TruthCourt is an AI-powered message and claim analysis system that detects misinformation and suspicious content using a debate-based reasoning approach. The system simulates a virtual courtroom where AI agents debate claims before delivering a final verdict.

The platform leverages **LLMs, retrieval augmented generation (RAG), semantic embeddings, and real-time web search** to provide evidence-based analysis.

---

# Project Overview

TruthCourt analyzes messages or claims by running structured debates between AI agents. Two AI lawyers analyze the content from opposing perspectives while a judge agent evaluates their arguments and produces a final verdict.

The system uses **semantic similarity search and vector embeddings** to retrieve past cases and reduce redundant processing.

# 🧠 AI Architecture

The system follows a **multi-agent reasoning architecture**.

1. **Similarity Check (RAG Pipeline)**  
   Incoming message is converted to embeddings and compared with previous cases using semantic similarity.

2. **AI Debate Simulation**  
   - Prosecutor AI analyzes potential misinformation  
   - Defender AI validates the claim using evidence  
   - Multiple debate rounds refine reasoning

3. **Judge Verdict System**  
   The judge agent evaluates the arguments and produces:
   - Final verdict
   - Evidence summary
   - Reasoning explanation
